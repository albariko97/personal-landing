A collection of developer tools and MCP servers purpose-built to connect AI agent runtimes with enterprise infrastructure environments.

### Capabilities
- **Platform Telemetry Connector:** Exposes read-only OpenTelemetry and Azure Resource Graph queries to local AI agents through standard MCP tool declarations.
- **Terraform Plan Summarizer:** Automatically inspects plan JSON outputs to classify blast radius, identify drift risks, and generate clear commit-ready changelogs.
- **Zero Config CLI:** Bundled with pure Node.js / TypeScript, runnable via `npx` with zero ambient system dependencies.
