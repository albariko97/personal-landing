Colección de herramientas de terminal y servidores MCP construidos para conectar entornos de agentes de IA con plataformas e infraestructura cloud empresarial.

### Capacidades
- **Conector de Telemetría de Plataforma:** Expone consultas de sólo lectura a OpenTelemetry y Azure Resource Graph a agentes locales mediante herramientas MCP estándar.
- **Analizador de Planes de Terraform:** Inspecciona automáticamente salidas JSON de planes de Terraform para clasificar radio de impacto, identificar riesgos de deriva y redactar resúmenes listos para revisión.
- **CLI sin Configuración:** Empaquetado en Node.js/TypeScript nativo, ejecutable mediante `npx` sin requerir instalaciones pesadas.
